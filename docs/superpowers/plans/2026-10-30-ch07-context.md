# ch07 上下文管理实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把简单裁剪升级为单会话三层上下文：近期原文、中期截短、远期异步摘要，并补齐预算、日志、只读接口与会话侧栏。

**Architecture:** 以 `summary_upto_msg_id` / `layer1_from_msg_id` 两个锚点切三层；`ContextBuilder` 每轮从 `messages` 表重建计划并写锚点；`agent_node` 用固定 system + 三层 + 尾随摘要/证据拼模型上下文；`SummaryService` 在回复结束后异步压缩层 2 并追加分段；LangGraph `State.messages` 用 `add_messages` 保存完整历史。

**Tech Stack:** Python 3.12、FastAPI、SQLAlchemy 2、LangChain 1.7（`trim_messages`）、LangGraph 1.2（`add_messages` + checkpoint）、MySQL/SQLite、原生 JS。

**Spec:** `docs/superpowers/specs/2026-10-30-ch07-context-design.md`

## Global Constraints

- 只管当前会话；不跨会话、不存用户画像。
- `tool` 行保留在数据库；模型上下文只含 `user`/`assistant` 最终消息。
- 默认 `MODEL_CONTEXT_WINDOW=32768`；演示用 18000，且必须算出 `history=5650`、`layer1=3954`、`layer2=1695`。
- system 每轮完全一致；摘要/证据放在当前用户消息之后的同一条 user 块里。
- 历史预算公式与常量以规格 §6.2 为准：`SYS` 含 5 个工具 schema，`E=top_k*400`，`R=steps*(tool_result+400)`，`M=316`，`want=20*600`。
- 摘要段只追加，不重写；触发看层 2 原始 token。
- 每轮打 `history_ctx`；每次调模型前打 `model_ctx`；摘要生命周期全留痕。
- 隐私：`.env`、`log/` 不入库；不回显 API key；不提交真实用户对话。
- 不修改全局 git config；不 force push；不动 ch02/ch03 Docker 卷。
- **每章只提交一次**：任务完成不单独 commit；章末统一提交「第十次提交（ch07）：…」。

`app/context.py`：

```python
import json
import math
from dataclasses import asdict, dataclass
from typing import Iterable

from langchain_core.messages import AIMessage, BaseMessage, HumanMessage
from langchain_core.messages.utils import trim_messages

from app.tools import FaqArgs, OrderArgs, ProductArgs, TicketArgs

CJK_START, CJK_END = "\u3000", "\u9fff"

@dataclass(frozen=True)
class ContextBudget:
    window: int
    output: int
    user_input: int
    system: int
    evidence: int
    react_peak: int
    safety: int
    summary: int
    wanted: int
    available: int
    history: int
    layer1: int
    layer2: int

    @classmethod
    def from_settings(cls, settings, *, summaries_tokens: int = 0) -> "ContextBudget":
        system = estimate_text_tokens(chat_system(settings.store_name)) + _tool_schema_tokens()
        evidence = settings.knowledge_top_k * 400
        react_peak = settings.workflow_agent_max_steps * (settings.tool_result_max_tokens + 400)
        available = (settings.context_window_tokens - settings.max_output_tokens
                     - settings.max_user_input_tokens - system - evidence - react_peak
                     - settings.token_safety_margin - summaries_tokens)
        wanted = settings.history_keep_rounds * settings.history_round_tokens
        history = max(0, min(wanted, available))
        layer2 = int(history * 0.3)
        layer1 = max(0, history - layer2 - 1)
        return cls(settings.context_window_tokens, settings.max_output_tokens,
                   settings.max_user_input_tokens, system, evidence, react_peak,
                   settings.token_safety_margin, summaries_tokens, wanted,
                   available, history, layer1, layer2)

    def startup_problem(self) -> str | None:
        if self.history <= 0 or self.layer1 <= 0:
            return (f"上下文预算不足：窗口 {self.window}，历史仅 {self.history}，"
                    f"层1 {self.layer1}。请调大窗口或缩小输出/步骤预留。")
        return None
```

`estimate_text_tokens` 用 CJK 区间与 `math.ceil`；`_tool_schema_tokens` 对 5 个工具 schema（`OrderArgs` 出现两次）`json.dumps` 后按同一口径估算；`estimate_tokens` 每条 `+8`，`tool_calls` 再 `+16`。

```python
def start_turn(self, *, user_id, message, conversation_id=None, with_message_id=False):
    with self.session_factory() as session:
        conversation = session.get(Conversation, conversation_id) if conversation_id else None
        if conversation is None or conversation.user_id != user_id:
            conversation = Conversation(user_id=user_id)
            session.add(conversation)
            session.flush()
        conversation.updated_at = func.now()
        message_row = Message(conversation_id=conversation.id, role="user", content=message)
        session.add(message_row)
        session.commit()
        if with_message_id:
            return conversation.id, message_row.id
        return conversation.id
```

3. `trim_messages` 裁剪，`token_counter=estimate_tokens`，`strategy="last"`，`start_on="human"`，`allow_partial=False`。
4. 新边界写回；`degraded=(old,new)`。
5. 层 2 = `S < id < L1`；计算原始 tokens；渲染后裁剪。
6. 返回 plan。

```python
class SummaryService:
    def __init__(self, model, store, settings, *, summarizer=None):
        self.store = store
        self.settings = settings
        self.summarizer = summarizer or Summarizer(model, settings.summary_timeout_seconds)
        self._tasks: set[asyncio.Task] = set()
        self._running: set[int] = set()

    def schedule(self, conversation_id, *, from_msg_id, upto_msg_id) -> bool:
        if not self.settings.context_summary_enabled:
            logger.info("summary skip conv=%s reason=disabled", conversation_id)
            return False
        if conversation_id in self._running:
            logger.info("summary skip conv=%s reason=running", conversation_id)
            return False
        logger.info("summary schedule conv=%s from=%s upto=%s", conversation_id, from_msg_id, upto_msg_id)
        self._running.add(conversation_id)
        task = asyncio.create_task(self._run(conversation_id, from_msg_id, upto_msg_id))
        self._tasks.add(task)
        task.add_done_callback(lambda item: self._finish(conversation_id, item))
        return True
```

`_run`：start 日志 → `to_thread(store.messages_between)` → `summarizer.summarize` → `to_thread(store.append_summary, ...)`；`None` 记 `summary skip stale`；异常记 `summary failed`；成功记 `summary done` 带 seq/chars/elapsed。

`_finish`：移出 `_running`/`_tasks`，不重复抛异常。
`wait`：循环 `asyncio.gather(*list(self._tasks), return_exceptions=True)` 直到空。

```python
def configure_file_logging(path: str) -> None:
    if not path or path == ":memory:":
        return
    target = Path(path).resolve()
    target.parent.mkdir(parents=True, exist_ok=True)
    root = logging.getLogger()
    if any(isinstance(h, logging.FileHandler) and Path(h.baseFilename) == target for h in root.handlers):
        return
    handler = logging.FileHandler(target, encoding="utf-8")
    handler.setLevel(logging.INFO)
    handler.setFormatter(logging.Formatter("%(asctime)s %(levelname)s %(name)s %(message)s"))
    root.addHandler(handler)
```

# ch06 开发留痕：分流器正式版

## 阶段 1：brainstorm 定稿

**用户关键原话**
- 「用 Superpowers 模式把客服系统里占位的分流器做成正式版，这是 Workflow 里最关键的节点。」
- 「指代消解：LLM 结合对话历史，把『它能退吗』补全成不依赖上下文的完整问题；已完整、指代明确的原样透传，不强行改写。」
- 「Query 扩写……强制 JSON 输出，字段只有 `queries` 一个数组……只对退款退货、售后这类高频、容错低的核心场景做，简单 FAQ 不扩；扩写放检索侧现查现用，库里知识只留一份，不在入库侧拆存多份。」
- 「意图识别用 LLM prompt 路线（不训分类模型）……留『其他』兜底类，拿不准就归它。」
- 「缺订单号不让模型猜，执行阶段弹订单选择器让用户点选回填；退款原因不追问，用户提交退款单时从固定类目自选。」
- 「默认配够格的大模型先把准确率做上去，成本吃紧时再走降级路：小模型给判断和置信度，置信度低才升级大模型重判一次。」

**关键产出**
- 规格：`docs/superpowers/specs/2026-10-30-ch06-router-design.md`
- 现状核对：`coref_node` 是透传占位；`INTENT_SYSTEM` 七类、无 `confidence`、无「其他」；`ROUTES` 里退款退货走 `knowledge`、售后走 `agent`；检索只有单问法 `retrieve`。
- 定稿决策：
  1. 出口 4 → 5（新增 `policy`），`其他 → agent`。
  2. 指代消解与口语归一合并成一次 LLM 调用；订单卡片点击路径用确定性合并兜底。
  3. 扩写只在 `policy` 路由做，2–3 条、第一条保留原意；检索侧 `retrieve_expanded` 合并去重 + 每问法重排取 max。
  4. 退款子流程 = `policy_order`（确定性取单）→ `policy_retrieve`（扩写 + 强制检索）→ Agent 判断「这一单」。
  5. 退款单复用 `tickets` 表（类型售后），不执行真实退款；原因 6 类白名单。
  6. 订单卡片数据来自 `tools.ORDERS` 演示数据；不新增用户-订单表。

**我拒绝或纠偏了什么**
- 拒绝给「其他」当默认兜底垃圾桶：只有低置信或模型失败才落「其他」，能判则判。
- 拒绝把扩写放在入库侧（用户已明确）；也不接受扩写成自由文本，必须只有 `queries` 字段。
- 拒绝让 Agent 自己去找订单号：订单号只从用户文本确定性提取，查不到就弹选择器。
- 拒绝在本章实现「小模型 → 大模型重判」的降级链路：只落 `confidence`，留好接口；用户原话是「成本吃紧时再走」。
- 没有新增用户-订单关系表：超出本章范围，规格里写明演示数据口径。

**翻车与返工**
- 暂无代码改动。核对文档时发现本会话没有挂载 Context7 MCP（`mcp_list` 查不到 context7），改为核对本机包版本（`langchain-core 1.6.5` / `langgraph 2.13.5`）与 ch05 已验证 API，记录在规格 §17；后续若涉及新 API 仍需先读已装包源码。

### 任务 5：多问法检索合并（retrieve_expanded）

**用户关键原话**
- 「几条一起检索再去重合并。」
- 「扩写放检索侧现查现用，库里知识只留一份，不在入库侧拆存多份。」

**关键产出**
- `RetrievalResult` 增加 `queries`；`retrieve()` 的命中/未命中都带上规范化查询。
- `KnowledgeRetriever.retrieve_expanded(queries)`：清洗去重（最多 5 条）→ 每个问法各自检索 → 同 id 同指标取 max → 按最高分排序 → 按 `(section_path, answer)` 内容去重 → 重排 → 阈值闸门 → 编号。
- 测试追加 4 条（合并取 max、内容去重、阈值拒答、空查询零模型调用）。

**我拒绝或纠偏了什么**
- 计划的实现片段是「每条问法都对全部合并条目重排」，但计划的验收断言是 `[2,3,1]`；两者不一致（按片段跑会得到 `[2,1,3]`）。按验收断言与规格「每问法重排取 max」改为：每个问法只重排自己召回的那批条目，再按 id 取各问法的最大分。规格意图未变，测试全部转绿。
- 新增用例显式 `synonyms=False`：`PerQueryStore` 用原问法做 key，而生产会把 `退款` 扩成 `退款 退钱 返钱` 去查稀疏侧；关掉同义词才能单测合并逻辑，生产行为不变。

**翻车与返工**
